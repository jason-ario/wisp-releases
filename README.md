# Wisp downloads

Download Wisp from the [latest release](https://github.com/jason-ario/wisp-releases/releases/latest), or from heywisp's website.

- **Windows:** `Wisp-Windows.exe`. No install needed: double-click to run. Windows may say it's unrecognized because the app isn't code-signed yet: click **More info → Run anyway**.
- **Mac:** `Wisp-Mac-arm64.dmg` (Apple silicon) or `Wisp-Mac-x64.dmg` (Intel), when available.

Wisp tells you when a new version is out.
